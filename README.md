# DengAI: Predicción de la Propagación del Dengue

Este proyecto tiene como objetivo predecir la propagación del virus del dengue utilizando técnicas de **Machine Learning** y análisis de datos climáticos. El trabajo está organizado en dos actividades principales.

## Contenido del Proyecto

El repositorio se encuentra organizado en las siguientes carpetas:

- **[Actividad 1](https://github.com/AlexPrietoRomani/DengAI-Predicting-Disease-Spread/tree/master/Actividad%201)**: 
  - Análisis exploratorio de los datos.
  - Preprocesamiento inicial.
  - Modelado básico para la predicción de casos de dengue.
- **[Actividad 2](https://github.com/AlexPrietoRomani/DengAI-Predicting-Disease-Spread/tree/master/Actividad%202)**:
  - Mejora de modelos anteriores.
  - Optimización de hiperparámetros.
  - Evaluación más profunda y validación cruzada.

Cada carpeta contiene scripts en Python y notebooks que documentan cada paso del flujo de trabajo.

## Objetivo

Predecir la cantidad de casos de dengue en diferentes ciudades, utilizando información climática histórica y otras variables relacionadas.

Este proyecto se basa en la competencia **DengAI: Predicting Disease Spread** de DrivenData.
